# Clean Commit Workflow

All commits in this repository follow [Clean Commit](https://github.com/wgtechlabs/clean-commit).

Use `<emoji> <type>: <description>` or `<emoji> <type> (<scope>): <description>`.
Valid types are `new`, `update`, `remove`, `security`, `setup`, `chore`, `test`, `docs`, and `release`. Use the matching emoji from the Clean Commit specification, present tense, no trailing period, and a description under 72 characters.
