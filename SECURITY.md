# Security policy

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/wgtechlabs/ph-scam-db/security/advisories/new) for vulnerabilities in the code, build pipeline, or repository automation. Do not open a public issue before maintainers have assessed the report.

Phone-number reports and appeals are community-safety moderation matters, not software vulnerabilities. Use the matching issue form and never include private evidence in a public issue.

## Supported versions

Until the first stable release, only the latest commit on `dev` is supported. Security fixes will be documented in the repository history and released through the normal review process.
