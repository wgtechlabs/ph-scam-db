Look up a report

Fetch the complete public index and match a normalized E.164 number.

(async () => {
  const db = await fetch(
    'https://wgtechlabs.com/ph-scam-db/data/index.json'
  ).then((r) => r.json());

  const report = db.entries.find(
    (entry) => entry.number === '+639171234567'
  );
})();

Use the confirmed blocklist

Use the smaller confirmed-only feed for a block or warning decision.

(async () => {
  const blocklist = await fetch(
    'https://wgtechlabs.com/ph-scam-db/data/blocklist.json'
  ).then((r) => r.json());

  const isBlocked = blocklist.includes(
    '+639171234567'
  );
})();
